# 기기 화면 크기 추정과 직접 보정

이 기능은 물리적 화면 크기의 **초기 추정값**을 제공합니다. 브라우저는 실제 기기 모델이나 정확한 물리 길이를 알려주지 않습니다. 기하 계산은 바꾸지 않으며, 측정한 값과 사용자가 가져온 보정값이 자동 추정보다 우선합니다.

## 판정과 계산

`estimateDeviceCalibration`은 iPhone 사용자 에이전트, `screen.width`, `screen.height`, `devicePixelRatio`를 함께 확인합니다. 화면 CSS 크기의 짧은 축과 긴 축에 DPR을 곱한 값이 검증된 Apple 화면 해상도와 일치하면 사양 후보로 표시합니다. 수치 오차 허용 범위는 각 축 1픽셀입니다. 사용자 에이전트만으로 모델을 확정하지 않습니다.

가로·세로 물리 길이는 `nativePixels / pixelsPerInch × 25.4`로 계산합니다. 이는 패널을 감싸는 직사각형 기준이며, 둥근 모서리·노치·Dynamic Island를 제외한 완전한 사용 가능 영역을 뜻하지 않습니다.

`identified: true`와 `confidence: 'signature-match'`는 지원하는 화면 사양과 일치한다는 뜻입니다. 정확한 모델 식별 또는 실측 확인을 뜻하지 않습니다. Display Zoom, 화면 배율, UA 변경, 브라우저의 축소·확대 좌표 때문에 잘못 일치할 수 있습니다. 자로 확인하는 보정이 우선합니다.

특히 **375 × 812 CSS 픽셀, DPR 3**은 iPhone X 계열과 mini 계열의 논리 좌표가 겹칠 수 있으므로 자동 판정에서 제외합니다. 기기를 아는 사용자는 검증된 사양을 직접 선택할 수 있습니다. `calibrationFromDevicePreset`은 `confidence: 'manual-spec'`를 반환하며 실제 브라우저의 CSS 화면 크기를 유지하여 표시 영역의 비율을 계산합니다.

Android, 데스크톱 모드, 모르는 화면 사양, 잘못된 수치는 68 × 147 mm의 **미확인 추정값**으로 돌아갑니다. 이 값은 측정치가 아니며 자동으로 실제 기기 크기라고 적용하면 안 됩니다.

## 패널과 현재 표시 영역은 다릅니다

`estimateViewportMm(profile, widthCss, heightCss, orientation?, visualViewportScale?)`은 현재 캔버스/레이아웃 표시 영역의 CSS 크기를 대응하는 화면 CSS 크기로 나눈 비율을 물리 패널 크기에 곱합니다.

- 세로 패널: 짧은 축을 너비, 긴 축을 높이로 사용
- 가로 패널: 두 물리 축과 CSS 화면 축을 함께 교환
- 브라우저 도구 모음, 상·하단 여백, 패널을 제외한 캔버스는 전체 화면보다 작게 계산
- 화면보다 큰 비율은 1로 제한하고 경고
- 유효한 결과는 보정 허용 범위의 하한 0.1 mm 이상, 해당 패널 길이 이하
- 잘못된 표시 영역 입력은 전체 패널 추정값과 경고를 반환하므로 자동 적용을 피할 것

방향을 생략하면 화면 CSS 크기에서 추론합니다. 표시 영역의 가로세로 비율로 방향을 추론하지 않습니다. 세로 화면에서도 키보드나 도구 모음으로 높이가 줄 수 있기 때문입니다. 가능한 경우 실제 화면 방향을 명시합니다.

`visualViewportScale`은 진단용입니다. 1이 아니거나 유효하지 않으면 경고합니다. 확대 중인 값에 자동 보정을 적용하지 마세요. 이 함수는 서로 다른 좌표 체계인 레이아웃 CSS 크기와 visual viewport 크기를 임의로 혼합하거나 배율을 조용히 곱하지 않습니다.

## 적용 순서

1. URL/가져오기 보정값, 사용자가 직접 입력한 물리 치수는 유지합니다.
2. 지원 사양이 확인되었거나 사용자가 사양을 직접 선택하고, 자동 크기 상태를 명시적으로 켠 경우에만 표시 영역으로 계산한 치수를 적용합니다.
3. 전체 화면 요청이 허용되었다는 가정만으로 패널 전체를 사용하지 않습니다. 요청이 완료된 뒤 실제 캔버스 크기를 다시 측정합니다. iPhone Safari에서는 전체 화면이 거절되거나 지원되지 않을 수 있습니다.
4. 전체 화면 실패 시에도 실제 현재 캔버스 비율로 추정할 수 있습니다. 전체 화면이 되었다고 표시하면 안 됩니다.
5. 생성 후 화면 방향이나 크기가 달라지면 경고하고 다시 생성하도록 안내합니다. 관찰 중 기하·보정값을 조용히 바꾸지 않습니다.
